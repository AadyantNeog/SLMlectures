# Organized Lecture Transcripts

These are readability-formatted versions of the original Stanford CS336 Spring 2026 lecture transcripts. The source `.txt` files in `../transcripts/` remain unchanged.

## Preservation policy

- Every original non-whitespace character is preserved in the same order after Markdown escaping is decoded.
- Repetitions, filler words, grammatical slips, transcription errors, stage directions, and `>>` speaker markers are unchanged.
- Only lecture titles, topic headings, paragraph breaks, whitespace normalization, and invisible Markdown escaping were added.
- Topic boundaries come from the companion lecture notes and follow the original transcript order.
