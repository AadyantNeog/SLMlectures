# Stanford CS336 Spring 2026 - Lecture Notes

This folder contains a separate Markdown note for each lecture in the Language Modeling from Scratch course.

Course playlist: [Stanford CS336 - Language Modeling from Scratch](https://youtube.com/playlist?list=PLoROMvodv4rMqXOcazWaTUHhq-yembLCV&si=nVODEdvz8lvNku3N)

## Source boundary used throughout

Every substantive topic is divided into two layers:

1. **What the lecturer said - transcript only.** A cleaned, concise paraphrase of the lecture transcript. This layer preserves substantive definitions, arguments, examples, qualifications, numbers, warnings, and audience questions without adding outside claims.
2. **Additional explanation.** Independent intuition, derivations, examples, organization, and study guidance.

Slides were inspected after each transcript map was established. When a slide supplies precision not spoken in the transcript, that information appears separately under **Source reconciliation**.

Each note includes its transcript line ranges, consolidated takeaways, important equations where relevant, a glossary, self-check questions, and a source-coverage checklist.

## Suggested study workflow

1. Read the lecture map and transcript-only layer first.
2. Use Source reconciliation to verify equations, names, figures, and slide-only numerical detail.
3. Read Additional explanation after the lecturer's account is clear.
4. Review the equation sheet and glossary.
5. Answer the self-check questions without looking back.
6. Use the transcript line ranges when auditing a claim against the raw source.
